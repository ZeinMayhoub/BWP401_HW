# مُلتقى | دليل فعاليات الجامعة الافتراضية

موقع ويب عربي يساعد الطلاب على استكشاف الفعاليات والأنشطة الجامعية والتعرّف على تفاصيلها.

## الصفحات

- **الرئيسية (`index.html`):** الفعاليات المميزة، التصنيفات، وأحدث الفعاليات.
- **الفعاليات (`events.html`):** استعراض الفعاليات والبحث عنها وتصفيتها.
- **تفاصيل الفعالية (`event.html`):** عرض معلومات الفعالية وصورها.
- **من نحن (`about.html`):** نبذة عن المشروع.
- **تواصل معنا (`contact.html`):** نموذج للتواصل مع التحقق من المدخلات.

## التقنيات المستخدمة

- HTML5 وCSS3
- JavaScript
- Bootstrap 5.3.8 مع دعم RTL
- Bootstrap Icons
- خط Cairo

## تشغيل المشروع

1. قَُم بتنزيل المستودع أو انسخه باستخدام Git.
2. افتح مجلد المشروع في Visual Studio Code.
3. شغّل `index.html` باستخدام إضافة **Live Server**، أو افتحه مباشرةً في المتصفح.

> يعتمد المشروع على ملفات الواجهة الأمامية، وتُحمّل مكتبات Bootstrap وBootstrap Icons من روابط CDN.
